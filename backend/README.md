# AI Agent Platform Backend

This backend provides the initial Spring Boot skeleton for an agentic AI productivity platform.

## Run locally

```bash
mvn spring-boot:run
```

## Endpoints

- Auth: `/api/auth/signup` and `/api/auth/login`
- Chat: `/api/chat/message`
- PDF: `/api/pdf/extract`
- Email: `/api/email/draft`
- Planner: `/api/planner/tasks`
